# NLP Sentiment Analysis: Customer Reviews Classification

**Prepared by:** Guy Berelzon & Ariel Sobol

## Overview
This project focuses on Text Mining and Natural Language Processing (NLP) to classify customer reviews into positive (1) or negative (0) sentiments. Using a bag-of-words approach and TF-IDF transformation, we evaluated multiple machine learning algorithms to identify the most robust model for high-dimensional sparse text data.

## Methodology
* **Feature Extraction:** TF-IDF (Term Frequency-Inverse Document Frequency) was used to down-weight commonly used words and emphasize discriminative terms across the vocabulary.
* **Validation Strategies:** We rigorously tested three cross-validation strategies to ensure real-world reliability and prevent data leakage or lucky splits:
  1. 80/20 Stratified Split
  2. 10-Fold Cross-Validation
  3. Stratified 10-Fold Cross-Validation (Ensuring the exact 62/38 positive-to-negative ratio in every single fold).
* **Models Evaluated:** Logistic Regression (L1 Lasso & L2 Ridge), Linear SVM, Random Forest, Gradient Boosting, and XGBoost.

## Key Findings & Data Science Decisions
* **Model Suitability:** Tree-based models (Random Forest, Gradient Boosting, XGBoost) underperformed compared to linear models. Linear models and SVMs are structurally better suited for handling the high-dimensional, sparse matrix (97.79% sparsity) generated by text data.
* **Regularization (L1 vs. L2):** Ridge Regression (L2) consistently outperformed Lasso (L1). Shrinking the weights of all features was more effective than aggressively eliminating them, allowing the model to capture subtle sentiment signals spread across hundreds of words.
* **Validation Stability:** Stratified 10-Fold Cross-Validation proved to be the most reliable evaluation method. It yielded the lowest standard deviation and guaranteed class balance across all folds, making it highly trustworthy for noisy text mining tasks.

## The Winning Model
**Logistic Regression (L2 Penalty, C=7.0)**
* **Validation Strategy:** Stratified K-Fold (K=10)
* **Accuracy:** 85.60%
* **Precision:** 86.15%
* **Recall:** 91.55%
* **AUC:** 0.9320

## Conclusion
The final model was trained on the entire dataset of 2,000 samples and applied to a rollout dataset to successfully predict and classify sentiments for new, unseen customer reviews.
